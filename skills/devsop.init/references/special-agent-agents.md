DEVSOP) is force-refreshed to the template version on every init/upgrade**; segments A (header + 1. Quick Index) and C (3. Development Guidelines + 4. Prohibited Red Lines) keep project customization.

Therefore, for the entire "2. DEVSOP" chapter:

- **Prohibited** to rewrite / condense / rework / move down / relocate — preserve it verbatim.
- **The only allowed action**: if the chapter is missing, truncated, or has drifted from the `## 2.` ~ `## 3.` span of `$SKILL_DIR/assets/agents.md.tmpl` → restore that span **verbatim** from the template; free rewriting is prohibited.
- Reason: ① if changed, the script will roll the whole section back on the next run — invalid churn; ② DEVSOP is the core contract of the standard development process (context recovery / task isolation / startup prerequisites / 9 steps / small-requirement mode / five-phase procedure + time logging / Commit sequence + boundary points A/B + one MR one commit) — free condensation will inevitably lose the essence; the essence can only be maintained in a single place, the skill template.
